# 收午饭入卡池

用户会发来 **照片（餐厅门头 / 菜单 / 菜品）+ 一行文字说明**，你要把它变成午饭卡池里的一张牌。

## 处理步骤

1. **看照片**认出：店名（门头招牌、菜单抬头、小票都算）、分店名（括号里的，如「阳光天地店」）、招牌菜（写进 notes）。
2. **读文字**提取属性，用户的话优先于照片推断：
   - 标签：`清淡 / 荤 / 重口 / 面 / 蔬菜 / 素`（可多个，逗号分隔）
   - 预算：数字（元）；没提就省略（工具默认占位 25，回执里注明「预算待补」）
   - 步行分钟：数字；没提就省略
3. **调用 `chouka_add_lunch`**：
   - `name`：店名（带分店），如 `老乡鸡(阳光天地店)`；用户文字里点名了菜就以菜为主
   - `tags`：从文字取；文字没给标签时按菜品判断（汤面/蒸菜→清淡，红烧/大肉→荤、重口），并在回执里说明是你判断的
   - `notes`：写来源和招牌菜，如 `来自 IM 照片：招牌番茄牛腩面，评分 4.5`
   - `budget` / `walk_minutes`：有就传，没有就不传
4. **回执一行**：`已入池 · <店名> · <标签> · ¥<预算|待补> · 步行<分钟|?>分钟`

## 红线

- 照片认不出店名就**问用户**，不要编一个像样的名字 ✗
- 只入池，**不点外卖、不打电话、不发帖** ✗
- 同名报错（「卡池里已有」）时回执 `已在池里：<店名>`，不要改名字硬加
- 不确定标签时宁可少打标，让用户之后自己改数据文件

## 数据在哪

卡池文件：`~/.dsh/chouka/data/lunch.json`（发布模式）。用户想批量修正预算/标签/停用某家（`enabled: false`）就改这个文件；改动即时生效，不用重启。
